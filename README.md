# Hello World - GitHub Pages

간단한 Hello World 웹페이지입니다.

## 배포 방법

1. GitHub 저장소의 **Settings** → **Pages** 메뉴로 이동합니다.
2. **Source**에서 `Deploy from a branch`를 선택합니다.
3. **Branch**를 `main` (또는 원하는 브랜치)으로 설정하고 `/ (root)` 폴더를 선택합니다.
4. **Save**를 클릭하면 몇 분 후 `https://<username>.github.io/<repo>/` 에서 접속할 수 있습니다.
